2. Key Technical Concepts:
   - Guillotine cutting with stage limit: **cut level = rotation number**, so every node level ≤ max_rotations (from GibLab help figure cs_params3 and "x - уровень команды, т. е. номер поворота"). The old optimizer allowed max+1 levels; this is now fixed: `_Cfg.max_level` = last container level = max(2, max_rotations) − 1, `_fill_exact` handles the deepest level, `_depth_ok` lim = max(2, max_rotations), and the validator has a depth check.
   - Column/strip packer (colpack): numpy 0/1 knapsack (binary bundles) for column content; Row model with cells (vertical stacks); mixed rows; composite columns; greedy/knap/dfs modes; weights.
   - Bin completion (DFS to exactly K=LB sheets with slack pruning) and Sequential Value Correction (SVC) with randomized α.
   - Improvement phase time budgets (IMPROVE_BUDGET); deep fit-all search (col_weighted, col_dfs, randomized tree with noise) only at one-off call sites.
   - GibLab .project semantics: cSizeMode dims (l/w, dl/dw, jl/jw), minusCount, elRoundMat/elRoundLength codes (decimals×10 + mode 0/1/2), cCostType 0–3, cCostByItem, cCostByItemRound 11–34, cCPF/cFillRep (both 0.9 in the corpus means 90%), cTrimEL/EW, sheet-level trim overrides, swSawthickDiv (−1 means none). Stats: cFilling = parts/(material − business).
   - Business rules: edge work = Σ side; edge material = Σ(max(side, min) + 2·overhang)·(1 + waste%); estimate = saw area × (2 − est%/100); price per sheet if cost_by_sheets, else per m² × (sheets area − business); sheet rounding geometric 1/k; multiplicity auto = ⌊pack/thickness⌋; effective qty = ОК − МК; min_part_size parts are excluded with a warning; product costs are per unit.
   - XNC stats: groove passes 1 + ⌈(W − D)/(0.7·D)⌉ (W < D → 0); an unresolved depth expression means the contour/groove is skipped and program mill = 0; compensation c=3 contours are not counted; arc length depends on direction (dir true = CCW).
   - Pydantic v2 before/after model validators for v1→v2 migration; React/AG Grid hotkeys scope system; i18n generator scripts/i18n_src.py (ru/uz, 880 keys).
