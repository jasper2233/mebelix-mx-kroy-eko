# Lisec (XOpt) — shisha kesish liniyasi (`.DAT`)

Generator: `ppfmt/saw_lisec.py` (kalit `lisec_xopt`). Manba: onlayn tizim fayllari (2026-10-24, 10 karta).
Zip ichida har karta `PL<NNN>.DAT` (UTF-8, CRLF):
```
[LPL_REF] MebeliX            ← onlaynda dastur nomi
[LPL_AUF] <loyiha nomi>
[LPL_AUFNR] Stroka?          ← onlayndagi doimiy (sozlama `order_no`)
[LPL_BREITE] <polosalar bo'ylab list o'lchami, sm>
[LPL_HOEHE] <ikkinchi o'lcham, sm>
[LPL_DICKE] <qalinlik, sm>
[LPL_TYPE] 1
[LPL_BV] <torsovka, sm>   [LPL_BU] <torsovka, sm>

[TRAVERE] <1-daraja polosa>
[Y_SCHNITT] <2-daraja> [BOCK_CODE] <detalning operatsiyadagi tartib raqami>
[Z_SCHNITT] <3-daraja> …
```
Sm, bitta kasr, 1 dan kichik qiymat nolsiz (`.2`). Propil va oxirgi chiqindi yozilmaydi. Faqat 3 daraja (`ROT_LIMIT` = 3).
