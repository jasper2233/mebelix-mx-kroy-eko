# E. Klaviatura yorliqlari — to'liq ro'yxat (kontekst bo'yicha)

Xodimlar bular bilan ishlaydi — **aynan shunday** bo'lishi shart. Frontendda yagona
`shared/hotkeys.ts` jadvali, kontekst = fokusdagi panel.

## E1. Loyihalar ro'yxati
| Yorliq | Amal |
|---|---|
| Ctrl+PgDn | Добавить (yangi loyiha) |

| Del, Shift+Del | Удалить (tasdiq bilan) |
| Ctrl+A | Выделить все |
